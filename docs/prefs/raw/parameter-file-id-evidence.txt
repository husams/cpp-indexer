Side finding from the hot path: parameter.file_id vs parameter.line/col

CallEdgeEmitter::mint_resolved_target (call_edge_emitter.cpp:148-150) builds a
DeclarationEdgeVisitor with target_file = {} and file_id = the CALL SITE's file,
then calls emit_signature_types_for. DeclarationEdgeVisitor::fill_signature_parameter
(declaration_edge_visitor.cpp:351-355) then writes
    record.file_id = file_id_;                 <- call site's file
    record.line    = expansion_loc(param).line <- parameter's real declaration line
so the (file_id, line, col) triple is inconsistent for any callee declared in
another file. Database: scratch index of src/query/exec.cpp + src/query/plan.cpp.
