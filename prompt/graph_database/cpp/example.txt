## Template instantiation

Find all concrete specializations of a class template:

```cypher
MATCH (tmpl:Node {kind: "TEMPLATE_DECL", qualified_name: "std::vector"})
      <-[:SPECIALIZES]-(spec:Node {kind: "SPECIALIZATION"})
RETURN spec.qualified_name, spec.file_path, spec.line
ORDER BY spec.qualified_name
```

## Virtual method override chain

Trace the full override chain for a virtual method:

```cypher
MATCH chain = (base:Node {kind: "METHOD", qualified_name: "Shape::draw"})
              <-[:OVERRIDES*1..]-(derived:Node)
RETURN [n IN nodes(chain) | n.qualified_name] AS override_chain,
       last(nodes(chain)).file_path AS defined_in
```

## Namespace membership

List all classes defined directly in a namespace:

```cypher
MATCH (ns:Node {kind: "NAMESPACE", qualified_name: "mylib"})
      -[:CONTAINS]->(cls:Node {kind: "CLASS"})
RETURN cls.qualified_name, cls.file_path, cls.line
ORDER BY cls.qualified_name
```

## Include graph

Find all translation units that (transitively) include a header:

```cypher
MATCH (tu:Node {kind: "MODULE"})
      -[:INCLUDES*1..]->(hdr:Node {kind: "HEADER", name: "widget.h"})
RETURN DISTINCT tu.file_path
ORDER BY tu.file_path
```

## Cross-repo references

Find all external references from repo A into repo B:

```cypher
MATCH (src:Node)-[:EXTERNAL_REF {via: "CALLS"}]->(dst:Node)
WHERE src.repo_name = "repo-a" AND dst.repo_name = "repo-b"
RETURN src.qualified_name AS caller,
       dst.qualified_name AS callee,
       src.file_path,
       src.line
ORDER BY caller
```

## Macro expansion sites

List all call sites that expand a specific macro:

```cypher
MATCH (site:Node)-[:EXPANDS_TO]->(mac:Node {kind: "MACRO", name: "CHECK_OK"})
RETURN site.qualified_name AS expansion_context,
       site.file_path,
       site.line
ORDER BY site.file_path, site.line
```
